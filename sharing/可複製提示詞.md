# 視覺題可複製提示詞

## 一、請 agent 規劃視覺題

```text
請把這個數學概念改編成一題視覺題。
先列出學習目標、唯一答案、四個選項與 lockedFacts，
再判斷應使用原卷裁圖、確定性繪圖或 AI 情境合成。
所有會影響答案的數字、數量、標籤、尺寸、幾何關係與線索位置，
都必須由程式或原始來源控制，不得交給 AI 生圖決定。
```

## 二、產生 AI 情境背景

```text
Use case: illustration-story
Asset type: background for a junior-high Wayground math visual puzzle
Primary request: <只描述故事場景，不描述答案>
Style/medium: polished educational illustration
Composition/framing: landscape 4:3 with generous negative space for overlays
Constraints: background atmosphere only; no readable text, no numbers,
no prices, no equations, no codes, no labels, no logos, no watermark,
no answer choices, and no exact object count that affects the solution.
All mathematical facts will be added later by deterministic code.
```

## 三、檢查 AI 圖是否適合

```text
請只檢查這張背景圖是否適合數學題合成：
一、是否出現可被誤認為題目線索的文字或數字；
二、是否有容易被學生拿來計數的重複物件；
三、是否保留足夠空間放置題幹與四個選項；
四、是否有任何物件暗示另一個答案。
不要修改數學條件。
```

## 四、請另一個 agent 驗題

```text
請不要參考既定答案，直接閱讀最終題圖並獨立解題。
回報你得到的答案、使用到的每一個視覺線索，
以及是否存在第二種合理解讀。
再將結果與 visual-spec.json 的 lockedFacts 比對。
```

## 五、建立分享包

```text
請使用 wayground-math-quiz 技能，
對指定 quiz.json 執行每題 visual-validate --strict、
整份 validate --strict、preview、prompt-pack 與 export-only。
分享包必須包含最終圖片、visual-spec、AI 背景、
提示詞、驗證報告與自含圖片預覽，不得包含登入資料或學生資料。
```
